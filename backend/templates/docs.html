API Documentation

Two endpoints. Two calls. That's the entire integration.

Introduction

The Auto-Pay Verification API allows you to accept UPI payments via FamApp and verify them automatically. By utilising our unique "amount fingerprinting" system, every transaction is matched perfectly without relying on manual screenshots.

FamApp removed the "Purpose:" field from notification emails. Our API solves this by adding 1–99 paise to the requested amount (e.g., ₹10.05), creating a unique fingerprint.

Authentication

To get your API key:

  1. Go to the Dashboard and sign in with Google.
  2. Use the Gmail account that receives FamApp notifications.
  3. Copy your 20-character API key.

You can pass the key in the query parameter or in the Authorization header:

Authorization: Bearer YOUR_API_KEY

1. Generate Payment QR

GET /qr

Generates a scannable UPI QR code with the fingerprint amount embedded.

Query Parameters

Name Required Description
upi Yes Your UPI ID, e.g., yourname@fam
amount Yes Base amount in rupees (integer)
bot_name Yes Display name shown to payer
remark Yes Unique alphanumeric string

Response Headers

The API returns a PNG image. You must read the X-Final-Amount header to know the exact fingerprint.

X-Final-Amount: 10.05
X-Base-Amount: 10
X-Paise: 5

2. Verify Payment

GET /api/verify

Checks if a FamApp email with the exact fingerprint amount arrived within the last 10 minutes.

Query Parameters

Name Required Description
key Yes Your API key
amount Yes The X-Final-Amount from step 1

Response (JSON)

{
  "verified": true,
  "received": 10.05,
  "status": "exact"
}

Python Implementation

Here is a complete example using requests.

import requests
import time
import secrets
import string

API_KEY = "YOUR_API_KEY"
UPI_ID = "yourname@fam"

def generate_remark(length=10):
    alphabet = string.ascii_uppercase + string.digits
    return "".join(secrets.choice(alphabet) for _ in range(length))

def create_qr(base_amount):
    r = requests.get("https://auto-payment.ximanta.xyz/qr", params={
        "upi": UPI_ID,
        "amount": base_amount,
        "bot_name": "MyBot",
        "remark": generate_remark(),
    })
    return r.content, float(r.headers["X-Final-Amount"])

def verify_payment(amount):
    r = requests.get("https://auto-payment.ximanta.xyz/api/verify", params={
        "key": API_KEY,
        "amount": amount,
    })
    return r.json()

# 1. Generate QR for ₹10
image_bytes, fingerprint = create_qr(10)
print(f"Show QR to user. They must pay exactly ₹{fingerprint}")

# 2. Poll for verification
for _ in range(10):
    res = verify_payment(fingerprint)
    if res.get("status") == "exact":
        print("Payment Successful!")
        break
    time.sleep(5)

Node.js / JavaScript

const crypto = require("crypto");

const API_KEY = "YOUR_API_KEY";
const UPI_ID = "yourname@fam";

async function createQr(baseAmount) {
  const params = new URLSearchParams({
    upi: UPI_ID,
    amount: String(baseAmount),
    bot_name: "MyBot",
    remark: crypto.randomBytes(5).toString('hex').toUpperCase(),
  });
  
  const res = await fetch(`https://auto-payment.ximanta.xyz/qr?${params}`);
  const imageBuffer = Buffer.from(await res.arrayBuffer());
  const fingerprint = parseFloat(res.headers.get("X-Final-Amount"));
  
  return { imageBuffer, fingerprint };
}

async function verify(amount) {
  const params = new URLSearchParams({ key: API_KEY, amount: String(amount) });
  const res = await fetch(`https://auto-payment.ximanta.xyz/api/verify?${params}`);
  return res.json();
}

// Usage
(async () => {
  const { fingerprint } = await createQr(10);
  console.log(`Ask user to pay ₹${fingerprint}`);
  
  setInterval(async () => {
    const result = await verify(fingerprint);
    if (result.status === "exact") console.log("Success!");
  }, 5000);
})();
