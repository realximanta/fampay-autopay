Privacy Policy

Last Updated: 2nd November 2026

1. Introduction

Welcome to Auto-Pay ("we", "our", or "us"). This Privacy Policy explains how we collect, use, disclose, and safeguard your information when you use our website, API, and mobile application. This service is operated by Himanta Bhuyan.

By using Auto-Pay, you agree to the collection and use of information in accordance with this policy.

2. Information We Collect

2.1 Google Account & Gmail Data

To function correctly, our API requires access to your Gmail inbox. When you sign in using Google OAuth, we request the following scopes:

  • gmail.readonly: We read emails solely to locate FamApp payment notifications and verify transaction amounts.
  • gmail.settings.sharing: We configure automatic email forwarding for FamApp notifications to a secure Cloudflare Worker to ensure instant payment verification.
  • userinfo.email: To identify your account and link it to your unique API key.

We do not read, store, sell, or share your personal emails. The system only scans for emails matching the exact FamApp payment template.

2.2 Authentication and API Data

We generate and store your API key. Your API key is required to query our verification endpoints. We store this key and your account expiry date in a secure Cloudflare KV database.

3. How We Use Your Information

  • To verify UPI payments made via FamApp automatically.
  • To manage your API key, subscription status, and expiration.
  • To send you essential transactional emails (e.g., subscription expiry warnings) using our email provider.
  • To monitor and prevent abuse, fraud, or security breaches.

4. Data Retention

We retain your encrypted Google refresh token and API key for as long as your account is active. If you revoke your API key, the association between your key and your Gmail account is immediately destroyed. We do not retain email contents; they are parsed in memory and discarded.

5. Security of Your Data

The security of your data is paramount. We implement industry-standard measures:

  • Gmail refresh tokens are encrypted using AES-256-GCM before being stored.
  • All API communication is encrypted via HTTPS.
  • Payment data is verified using HMAC-SHA256 signatures to prevent tampering.

6. Your Rights

You have the right to:

  • Revoke our access to your Google account at any time via your Google Account Permissions.
  • Revoke your API key via the dashboard.
  • Request the deletion of your account and associated data by contacting us.

7. Third-Party Services

We utilize the following third-party services to operate:

  • Google Cloud Console: For OAuth authentication and Gmail API access.
  • Render: For hosting the backend API server.
  • Cloudflare: For KV database storage, Email Routing, and Workers.
  • Resend: For sending transactional emails.
